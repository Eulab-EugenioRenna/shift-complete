I toast reali sono quelli in alto a destra, generati dal feedback center condiviso.

Ogni pattern usato 2 volte deve uscire dal template locale.

Tag, chip, badge, button e input non devono essere reinterpretati pagina per pagina.

Le shell di layout devono usare `ui-surface`, `ui-card`, `ui-sidebar-panel`, `ui-dialog-shell`.

I pattern operativi complessi vanno promossi a primitive dedicate solo quando sono davvero stabili.
